Meetly analyzes your meeting transcript to automatically identify tasks, commitments, and follow-ups — so nothing slips through the cracks. As soon as a summary is generated, action items are extracted and made available in the dashboard and via the API, ready to be reviewed, edited, or pushed to your project management tools.

## What Gets Extracted

Meetly's AI scans the transcript for natural-language signals that indicate something needs to be done. Specifically, it looks for:

- **Explicit task assignments** — statements like "John will send the report by Thursday" where a person and a task are clearly linked.
- **Commitments** — promises made by participants, such as "we'll have this done by Friday" or "I'll follow up with the client."
- **Follow-up items** — agenda-setting statements like "we should schedule a review meeting" or "let's revisit this next sprint."
- **Decisions requiring action** — conclusions that imply a next step, such as "we've agreed to move forward with Vendor B" where someone needs to initiate that process.

## Action Item Object

Each extracted action item is represented as a JSON object with context, ownership, and confidence information.

```json
{
  "id": "act_07nw4r2p9xtb6k1m5yvq8zh3cd",
  "meeting_id": "mtg_01hx9z3k7fqe2v8c4bnj6yd5rw",
  "text": "Send the updated project timeline to all stakeholders.",
  "assignee": {
    "name": "Alice Chen",
    "email": "alice@example.com"
  },
  "due_date": "2024-07-19T00:00:00Z",
  "status": "open",
  "confidence": "high",
  "created_at": "2024-07-15T15:02:10Z"
}
```

Key fields to note:

- `assignee` — the person the task was assigned to, as identified from the transcript. This is `null` if no clear owner was mentioned.
- `due_date` — an ISO 8601 date parsed from the transcript (e.g., "by Friday"). This is `null` if no date was mentioned.
- `status` — tracks progress: `open`, `in_progress`, or `done`. The initial status is always `open`.
- `confidence` — how certain the AI is that this item is a genuine action item: `high`, `medium`, or `low`.

## Reviewing & Editing

Review all extracted action items from the **Action Items** tab on the meeting detail page in your dashboard. You can edit the text, reassign the owner, adjust the due date, or delete items that were extracted incorrectly.

Items with a `confidence` score of `low` are automatically flagged with a warning indicator, prompting you to verify them before they're treated as confirmed tasks. You can also retrieve and update action items programmatically:

- `GET /v1/meetings/{meeting_id}/action-items` — list all action items for a meeting.
- `PATCH /v1/action-items/{action_item_id}` — update the text, assignee, due date, or status.
- `DELETE /v1/action-items/{action_item_id}` — remove an incorrectly extracted item.

## Integrating Action Items

Once action items are confirmed, you can push them directly into the tools your team already uses. Meetly supports the following integrations out of the box:

- **Jira** — creates issues in a project of your choice, with assignee and due date mapped automatically.
- **Linear** — creates issues in a team's backlog with priority and assignee set from the action item.
- **Asana** — creates tasks in a project, assigned to the relevant team member.

You can also use **webhooks** to receive action item payloads in real time and build your own integrations. Configure webhooks in **Settings → Webhooks** in the dashboard, or via `POST /v1/webhooks`.

<Tip>
  Set up a webhook to automatically push action items to your project management tool as soon as a meeting completes. This eliminates manual copy-paste and ensures tasks are captured before your next standup.
</Tip>
